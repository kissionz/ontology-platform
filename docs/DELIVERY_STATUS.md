## 本轮加固

- 快照、发布说明、草稿删除和发布审计处于同一个事务。
- 导入不再将旧草稿当作发布版本；任一版本或索引非法时整批回滚。
- full Context、HTTP/MCP 导出和短引用目录统一过滤敏感属性。
- 会话省略版本或指定 latest 时继续使用会话固定版本。
- 数据源凭据使用绑定 sourceId 的 AES-256-GCM 加密，保存配置后重建连接。
- 生产 MCP 经过与 HTTP 相同的认证、Scope、限流和审计。
- 公理关系闭包覆盖多跳路径；AUTO 业务值作为 SQL 参数传递。
- 写入支持进程内 10 分钟 Idempotency-Key 重试窗口；变更请求体复用同一 key 返回冲突。
- 发布后异步构建值索引，索引失败不会回滚已发布本体，并暴露失败状态。

- 澄清待办持久化 30 分钟，保留原候选与版本，重启可继续；失败可重试，成功后消费。
- FIXED_SHAPE 的 DIRECT 筛选复用持久化 SQL 模板，动态参数不写入模板；数组参数数量、物理 Schema 或版本变化会重新编译。
- 公共查询契约接通高级计算，共享 Zod、OpenAPI、MCP schema；HTTP 测试覆盖窗口占比、组内排名、组合条件、时间比较、累计与逐期条件。
- 发布前展示 Golden Cases 运行时间、revision、摘要与逐项结果；报告持久化并关联发布审计，发布重新校验当前草稿，未配置用例明确标记。
- 增加 GitHub Actions build、测试和 Chromium E2E 流程，截图路径兼容 macOS/Linux。
