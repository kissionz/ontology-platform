# 关系配置与输出

在对象草稿的“关系”页操作。新增、修改、删除随“保存对象”保存，通过公理校验并发布后用于新版本查询；历史版本仍使用自身定义。

| 类型 | 公理要求与输出行为 |
| --- | --- |
| 实体引用 | 引用方指向目标唯一标识，支持多对一或一对一；按方向建立查询路径。 |
| 业务关联 | 两端字段等值连接；数量关系中声明为“一”的端必须有唯一性声明，禁止不安全的重复聚合。 |
| 组成关系 | 明确整体、组成部分和归属方式。整体字段唯一，归属无环；独占组成部分不能同时归属其他整体对象。按整体维度汇总子对象指标时，查询从子对象事实粒度开始；“仅用于存在性筛选”只允许 EXISTS 筛选，禁止对象或指标展开。 |
| 层级关系 | 下级实体指向唯一上级实体，数量关系为多对一或一对一，实体层级不能成环。按配置方向连接并推理多步可达性；递归节点层级通过独立的层级定义配置。 |
| 事件参与 | 业务事件的实体引用字段连接参与实体的唯一标识。 |
| 身份对应 | 两端唯一标识一对一对应，按方向连接同一身份的不同对象定义。 |
| 派生血缘 | 来源对象派生自目标对象，记录字段映射，输出无环依赖和公理证据；不生成物理查询连接。指标计算仍由指标定义提供。 |

公共设置会影响以下输出：

- **方向**：决定可遍历方向。反向遍历会反转数量关系，多对一的反向是一对多，不会被标记为安全汇总路径。
- **启用**：停用关系退出查询路径和推理依据；删除关系在新版本中移除定义。
- **必须存在关联记录**：普通连接使用 INNER JOIN；可选关联使用 LEFT JOIN。存在性筛选使用 EXISTS。
- **数量关系、扩行风险**：检查唯一性声明并阻止高风险、多对多及会放大事实行数的聚合。声明本身不替代业务数据质量验证。
- **字段映射**：从两端选择的字段生成等值连接表达式。对象编码或字段映射更改时同步更新表达式与公理，避免配置与 SQL 不一致。

每条关系生成类型规则、字段映射、方向、基数等公理；推理结果保留来源定义、规则 ID 和证明步骤。查询要求返回公理或推理依据时，会包含实际查询计划使用的关系证据。

本轮使用本地合成数据验证发布前后的真实 SQL 结果变化、参数化 EXISTS、版本隔离和错误配置拦截。正式 SelectDB 业务内容验证按当前约定暂缓。
